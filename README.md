# singularity_oop

В этом учебном проекте я собираю ядро интернет-магазина и разбираюсь с ООП.

## Что уже есть

- `src/product.py` класс `Product` (товар): название, описание, цена и количество в наличии.
  Цена приватная, читается и меняется через свойство `price`. Нулевую или отрицательную цену
  поставить нельзя, в консоль выводится предупреждение. Если цена снижается, программа спрашивает
  подтверждение (y/n), и цена меняется только после ответа y.
  Класс-метод `Product.new_product(data)` создает товар из словаря. Если вторым аргументом передать
  список товаров и там уже есть товар с таким названием, то количество складывается, а цена берется большая.
- `src/category.py` класс `Category` (категория): название, описание и список товаров.
  Список товаров приватный. Добавить товар можно через `add_product()`, а свойство `products`
  возвращает строку со всеми товарами в виде `Название, 80 руб. Остаток: 15 шт.`
  У класса есть два общих счетчика, `category_count` и `product_count`.
  Они увеличиваются при создании категории и при добавлении товара.
- `src/utils.py` загрузка категорий и товаров из JSON файла (пример лежит в `data/products.json`).
- `main.py` небольшой пример использования классов.

## Домашняя работа 15.1

- У товара и категории теперь есть `__str__`. Товар выводится как `Чай, 80 руб. Остаток: 15 шт.`,
  категория как `Напитки, количество продуктов: 200 шт.` (тут складываются остатки всех товаров).
- Геттер `products` теперь просто делает `str()` от каждого товара.
- Товары можно складывать: `a + b` вернет цену × количество первого плюс цену × количество второго.
- Доп. задание: `CategoryIterator`, чтобы перебирать товары категории в `for`.

## Установка

```bash
poetry install
```

## Запуск

```bash
poetry run python main.py
poetry run python -m src.utils
```

## Тесты

```bash
poetry run pytest --cov=src --cov-report=html --cov-report=xml
```
